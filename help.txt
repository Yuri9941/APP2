Запуск на Fabric:
  npx rayfin login
  npx rayfin up
  Открыть приложение из Fabric portal (SSO) или hosting URL → «Войти через Fabric».
  Данные: сущность/таблица App2 (Data API), не ZHGOK_2026_test.

Локально (Express + MS SQL dbo.APP2) — оба процесса:
1) cd D:\YBKNIMEWS\APP2 && node index.js
   → http://localhost:5174
2) cd D:\YBKNIMEWS\APP2\client && npm run dev
   → http://localhost:5173

Внимание: Lakehouse Tables/APP2 в workspace 70HFM и таблица App2 в SQL Data App — разные хранилища.
Rayfin UI читает/пишет SQL Data App (сущность App2). Чтобы наполнить её, загрузите данные туда или синхронизируйте из Lakehouse отдельно.
