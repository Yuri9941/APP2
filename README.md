# Ручной ввод ZHGOK_2026_test

React-форма для просмотра автоматических значений и ввода/правки ручных данных в таблицу MS SQL `[dbo].[ZHGOK_2026_test]`.

## Запуск

### 1. Сервер (API и доступ к MS SQL)

```bash
cd server
cp .env.example .env
# Отредактируйте .env: укажите DB_SERVER, DB_DATABASE, DB_USER, DB_PASSWORD
npm install
npm start
```

Сервер будет доступен на `http://localhost:3001`.

### 2. Клиент (React)

```bash
cd client
npm install
npm run dev
```

Откройте в браузере `http://localhost:5173`. Запросы к `/api` проксируются на сервер.

## Поведение

- **Обновить** — загрузка данных из БД с учётом фильтров.
- **Принять** — сохранение введённых ручных значений в таблицу (`value_source='APP'`, `TMSTMP=GETDATE()`), затем обновление данных в интерфейсе.
- Данные автоматически обновляются каждые 15 минут.
- В правом верхнем углу отображается время последнего обновления.
- Фильтры: Бизнес-единица, Код MIRS, Дата смены, Номер смены (варианты подгружаются из БД).
